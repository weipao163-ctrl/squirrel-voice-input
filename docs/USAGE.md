# 使用说明

1. 从源码构建并安装后，重新登录 macOS，在“系统设置 → 键盘 → 文本输入”添加增强输入法并选择它。
2. 从输入法菜单打开增强设置。选择输入方案，启用字母选词，设置选择字母并保存/应用。输入拼音后按一次空格显示候选，再按字母选择当前页对应项；第二次空格确认当前高亮项。
3. 在“语音输入设置”选择服务模型，填写自己的服务信息。两个千问模型共用地域、工作空间与 API Key；豆包使用自己开通的语音服务资源及专用 Key，或旧版 App ID / Access Token。火山方舟的通用 Key 不等于已开通豆包语音识别权限。
4. 录制长按热键，选择麦克风；通过设置页申请麦克风和输入法焦点检测权限，按系统提示处理。无音频连接鉴权通过后，再在测试框按住说话、松手结束。
5. 正常使用时聚焦可编辑输入框，按住热键说话，松开后识别结果自动输入原位置。识别结束浮窗自动隐藏。需要原生润色时，在 Message 或豆包模型中启用对应开关。

语音测试和正常云识别都会上传音频到用户选择的服务，可能计费。服务可用性取决于账号认证、资源开通、地域、凭据和服务方策略，仓库不预置可用账号。

浮窗默认位于当前屏幕下方中央、程序坞上方；可以调整透明度或勾选显示在输入位置。拿不到有效坐标时回到默认位置。

如果录音后切换窗口、移动输入位置或输入会话失效，自动上屏会被取消，避免错写。可从输入法菜单“恢复语音草稿…”找回可恢复的识别结果。安全输入框和无法验证的目标不自动写入。

Finder 改名框通常已有文件名选区；增强版验证该选区后复用普通拼音提交路径。不会代替用户按回车完成重命名。
