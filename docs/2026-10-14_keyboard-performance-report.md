# 0.1.27：键盘响应与资源占用复查

0.1.26 已移除隐藏候选时的光标查询、推迟可见候选布局并复用外观。本轮补充持续输入、输入框重新激活和已安装进程采样，修复普通按键重复查询宿主应用标识的问题。

## 发现与实现

`handle(_:client:)` 在设置表单保护和应用配置检查中分别调用 `bundleIdentifier()`，按下和松开均会重复查询。该接口属于 IMK 客户端，真实宿主可能跨进程响应；无需在每个键上重新读取不变的应用标识。

现在按当前客户端对象缓存有效、非空的应用标识：缓存仅保存字符串，客户端使用弱引用；重新激活强制刷新，失活清理；不同客户端或未知/失败的标识重新查询。设置窗口的按键归属、真实光标位置、语音目标校验与系统安全输入检查继续使用各自的原通路，不把应用标识缓存当作输入位置证据。

## 性能与内存证据

生产输入控制器、真实 librime 1.17.0、AppKit 候选窗口与本地 IMK 客户端共同运行。两版均用 Swift `-O`；对照控制器取自 0.1.26，其他夹具与引擎相同，按旧/新顺序连续重复三轮。为测试宿主等待，应用标识查询人为等待 2 毫秒。

| 同一隔离负载 | 0.1.26 | 0.1.27 |
| --- | ---: | ---: |
| 240 次按下/松开中的应用标识查询 | 480 | 0 |
| 慢宿主负载耗时中位数 | 1239.5 ms | 8.7 ms |
| 12,000 次按下＋12,000 次松开的 CPU 时间中位数 | 0.400 s | 0.373 s |
| 按下处理耗时 p95 的中位数 | 0.037 ms | 0.034 ms |
| 持续输入后物理内存占用增长最大值 | 80 KiB | 64 KiB |
| 500 次重新激活后的物理内存占用增长最大值 | 80 KiB | 64 KiB |

这里的 CPU 时间是该进程完成固定工作量所用的用户＋系统时间，不是活动监视器百分比。内存取内核 `TASK_VM_INFO.phys_footprint`，预热后采样；测试运行循环有与应用事件循环相同的 autorelease 边界。未发现持续输入或重新激活造成无界增长，因此保留正常词库与字体缓存，不靠每键清空缓存降低数字。

**这些数值来自小型公开词库与隔离客户端，不代表所有真实网页、个人方案、整机输入速度或 CPU 百分比会改善相同倍数。** 真实跨进程等待取决于目标软件。安装后独立空闲观察采到主程序 CPU 0%、驻留约 60.3 MiB；Helper 未在该次观察中运行，因此没有本版 Helper 的占用数值。驻留内存与上述物理占用是不同口径，也受系统换页影响，不能混作同一基准。

## 回归与安全边界

32 项原生键盘/性能检查通过，含 100 个新控制器的首键、24,000 次持续事件、500 次激活、设置客户端归属、过期候选刷新和长原文。另有 159 项 Core、53 项 Lua/文件、31 项数字专项、7 项候选窗口、12 项认证 IPC 及完整安装包/空白默认词库检查通过。

初始化异常用例需要可控的安全输入状态。本地客户端夹具分别测试普通和安全状态；该测试符号只编译进工具，不进入发布程序，不切换系统安全状态。发布二进制仍链接 Carbon 的真实 `IsSecureEventInputEnabled`；安全输入下未就绪按键不暂存、不迟到重放。初次直接使用系统状态时有用例被环境安全状态阻止，未把那次运行记为通过；修复没有更改安全检查。

已安装程序从最终包的用户升级事务更新；文件逐一匹配，设置和个人词库保留。没有采音、API Key 导出或云识别。真实物理键盘、每个网页以及第二台 Mac 不由本轮组件检查替代。

## 复现与升级

按 [构建说明](BUILDING.md) 构建后运行 `python3 tools/run_native_keyboard_input.py`。该入口编译实际控制器，可用 `--label` 保存独立报告；`--controller-source` 可指定从旧标签保留的控制器做对照。候选窗口工具复用实际构建的 SDK，避免多 SDK 环境混用。

[安装说明](INSTALLATION.md)涵盖系统放行与输入源添加。本版 App/Helper 0.1.27，Apple Silicon、macOS 13+；没有 Apple Developer ID 公证，首次安装需在隐私与安全中手动允许。源码和包仅包含公开默认词库与默认外观，不带个人词库、用户设置、Key 或签名私钥。
