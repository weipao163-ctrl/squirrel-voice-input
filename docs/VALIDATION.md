# 验证范围

0.1.20 的开发过程曾在本机完成下列检查。原始本机报告含环境路径等信息，不随公开源码发布；本仓库提供重新运行检查的代码。

| 检查层 | 已有开发验证 |
| --- | --- |
| Swift Core | 159 项测试体；CLT 场景使用 Swift Testing 适配，保留原断言 |
| 原生编辑器与语音浮窗 | 105 项受控检查 |
| 候选窗口 | 7 项渲染/配置回归 |
| 原生目标快照 | 45 项受控 IMK 与窗口夹具 |
| PCM | 24 项合成音频转换/排空检查，未采集真人音频 |
| 字母 worker | 83 项真实 librime 夹具与负对照 |
| IPC | 34 项配置/启动/真实签名通信检查 |
| Rime 通知与位置策略 | 19 项检查 |
| Lua / 文件与安装事务 | 离线 Lua、真实 Rime、配方与隔离事务回归 |
| 开发安装包 | 解包文件匹配、签名、运行依赖及六个默认方案的空白数据候选检查 |

上述数量描述源版本开发时的范围，不表示 GitHub CI 已经运行，也不表示所有机器或应用通过。公开源码的重新构建、CI 和人工测试应各自报告真实结果。

本机使用者曾确认普通文本、豆包识别、微信网页回复框和 Finder 改名场景可用。Finder 修复后的成功来自使用者手动反馈，代理未额外采音或捕获完整改名过程。

尚未完成另一台 Mac、所有麦克风/应用、macOS 13 真机、完整 78 项目标验收和正式 Apple 签名/公证的全覆盖。不把组件或安装包测试当作这些场景的成功证明。
