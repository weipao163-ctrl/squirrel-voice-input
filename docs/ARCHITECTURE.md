# 架构

| 目录 | 责任 |
| --- | --- |
| `enhanced-squirrel/sources/` | Squirrel 前端、IMK 生命周期、Rime 提交、候选窗口、增强桥接和目标校验 |
| `enhanced-squirrel/Enhancements/Sources/EnhancementCore/` | 设置、按键/识别状态机、服务协议、PCM 策略、事务与草稿模型 |
| `enhanced-squirrel/Enhancements/Sources/EnhancementIPC/` | 同用户与进程/签名身份绑定的进程间通信 |
| `enhanced-squirrel/Enhancements/Sources/VoiceHelper/` | 设置界面、Keychain、权限、音频捕获和云识别连接 |
| `lua/`、`config/` | Rime 两阶段字母选词及增量补丁 |
| `tests/`、`tools/` | Lua、Swift Core、原生夹具、安装与构建验证 |

语音流程为热键按下 → 固定配置与设备 → 验证目标 → 采音和识别 → 松手并排空音频 → 再次验证目标 → 原生提交或保留草稿。完整结果到达前不会把每句中间识别直接写入目标。

普通拼音和语音共用输入控制器当前的 IMKTextInput。候选窗和语音使用同一个 KeyboardInputPosition.caret：首先查询相对内联会话的 attributes(index: 0)，不能把文档绝对偏移当成这个索引；缺失时使用已知选区对应的 firstRect。完整语音仍调用普通键盘 commit，包含宿主要求的 marked-text 兼容选项。

语音目标统一冻结原生客户端、输入代次、输入源、进程、原生选区/光标/窗口及可用的会话标识。AX 字段、窗口、选区和几何信息提供补充证据，不以应用名称、文本角色、AXValue 可写性或必需通知名单判定键盘输入能力。窗口优先通过当前 AX/CG 几何对应；原生弹出编辑器在 AX 父窗口外时，使用所属进程最前的原生窗口，不能从被遮挡的普通窗口中任意挑选。桌面窗口按实际层级和所有者判断。

正常光标/范围/窗口不依赖可选 uniqueClientIdentifierString，因为部分宿主每次查询都会返回不同标识；缺少原生范围或光标、必须借助会话标识时，要求连续查询返回一致。

已选文字遵循正常键盘的当前选区替换语义，开始后的选区改变会撤销提交。未实现的范围 API 保留 NSNotFound；缺少选区时必须另有原生会话标识和光标/窗口证据，无光标时必须另有 AX 字段/窗口、会话标识和已知选区，不能凭客户端指针或进程名称自动提交。不读取宿主正文或模拟插字来探测目标。

真实安全输入、密码控件、已禁用控件、未确认拼音和无法验证的目标不得自动提交。键盘、鼠标、滚动、应用/窗口、输入源、会话及系统状态变化由统一事件监听、原生复核和可用 AX 通知保护。最终结果提交前完整复核；改变的目标保留草稿。自己的 commit 前先退役原目标监听，避免同步上屏通知被误判为外部编辑。

Helper 和主程序须使用匹配的签名身份；ad-hoc 构建不能假装具备生产语音 IPC。配置事务和独立数据目录用于保护已有设置及词库。
