# 0.1.37：输入源变灰、中文和语音同时失效

2026-10-29。本机注册已修复，0.1.37 已构建并安装。本次未发布到 GitHub。保留本机个人词库和设置，公开安装包仅使用有来源记录的公开默认词库。

## 证据与原因

| 证据 | 实际观察 | 结论边界 |
| --- | --- | --- |
| E1：进程与签名 | 主程序、语音助手仍运行，主程序主线程在正常事件循环，签名校验通过，安全输入未开启 | 没有观察到崩溃或主线程卡死 |
| E2：系统注册 | `NSWorkspace.urlForApplication` 将增强版 Bundle ID 解析到工作区构建副本；系统另有同标识的历史构建、安装临时目录和 `.app` 备份记录 | 已确认日常安装路径不是系统首选路径 |
| E3：修复对照 | 仅强制注册安装目录未改变首选路径；解除确认为本项目副本的重复注册，再刷新安装目录后，解析恢复到用户的 Input Methods 目录 | 未重启进程即恢复前台输入会话，用户同时确认已恢复正常 |
| E4：源码 | 原 `register()` 发现模式已启用就返回；同包安装也跳过注册，升级备份仍使用 `.app` 后缀 | 已启用并不代表路径注册正确；这些路径让错误注册继续保留 |

F1（已验证，E2–E4）：安装注册恢复不完整，重复应用标识造成路径冲突。故障影响的是系统到输入法的会话建立，因此普通中文和依赖同一会话的语音会一起失效。

P1 调用路径：更新产生同标识 `.app` 来源/备份 → LaunchServices 选中了构建副本（E2）→ 安装代码因“已启用”未刷新（E4）→ 运行中的主程序没有有效前台输入会话 → 清除重复注册后，在相同进程中恢复（E3）。系统日志另有 IMK 连接名拒绝记录，但隐藏了 Bundle ID；不将这些日志单独归因于增强版，也没有改动已经符合规范的连接名称。

本地诊断资料保存在忽略目录 `evidence/disabled-input-20261029/`，包括进程采样、修复前后注册状态、重复记录清单、保护文件哈希和安装日志；含本机路径的原始资料不公开上传。无法从日志确定这次具体由哪个系统操作重新选中了构建副本，因此不声称已复现所有可能触发条件。

## 修复

- `SquirrelInstaller.register()` 每次明确刷新 LaunchServices 和 TIS。保留用户启用的模式，不再用“已启用”作为跳过注册的依据。
- 输入源列表按需重新读取，避免注册前快照被后续操作复用。这里仅属于安装命令，不进入按键处理路径。
- 安装事务只解除本次来源副本和旧包备份（包括内嵌 Helper）的注册，不重置全系统数据库，不处理其他输入法。重复安装相同包也执行注册修复。
- 备份、失败包、未完成包及卸载备份均保存为 `.app-backup`，避免被当作可启动应用。全部内容保留，恢复时移回原安装路径即可。
- 注册失败恢复旧应用后，也尝试刷新旧应用注册。发生后续文件修改时保留现场，不覆盖用户修改。

## 验证

- 9 项真实 Bash 安装事务检查通过，包括同包修复、失败回滚、来源/备份解除注册、后续修改和锁冲突。签名、LaunchServices 和 TIS 在这组隔离测试中是替身。
- 4 项正常退出准备检查通过。
- 93 项生产键盘控制器与真实 Rime 隔离检查通过。24,000 个按下/抬起事件的按下耗时 p95 约 0.036 ms；这是隔离夹具耗时，不是物理键盘端到端延迟。修复没有增加按键查询或常驻轮询。
- 12 项签名 IPC 与 11 项配置检查通过；安装包重新解包验证签名、文件一致性、公开词库、14 项字母选词及 6 个默认方案。
- 本机已安装 0.1.37，系统首选路径为正式安装目录，增强版简体模式已启用并选中。原 SharedSupport 的 63 个文件全部保留，正式 Rime 的 195 个文件哈希一致；增强版配置和源词库保持不变，Rime 的运行记录及学习数据库在正常运行/重启时允许更新。Keychain 未删除、重写或导出。

注册修复后用户先确认故障恢复；更新到 0.1.37 后，用户再次明确确认“中文正常，语音热键也正常”。代理本次未采音、未向云识别服务发送音频，也未执行长期跨休眠测试。自动化文本编辑按键未形成可确认的前台 IMK 测试会话，因此未计作实际中文上屏验收。

## 复验

在项目根目录运行：

```bash
python3 tests/test_app_install_transaction.py --bash /bin/bash
python3 tests/test_app_update_preparation.py
python3 tools/run_native_keyboard_input.py --label registration-repair
python3 tools/run_native_ipc_trust.py
```

后三项原生检查需要先按构建说明准备 macOS 构建环境。系统路径与真实输入验证需要实际安装后，在普通文本框中选择增强版，并核验中文候选、字母上屏和语音热键；不要把隔离检查当作实际应用验证。
