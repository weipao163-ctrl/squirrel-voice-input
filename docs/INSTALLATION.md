# 安装鼠须管语音增强输入法

## 系统要求与下载

- Apple Silicon（M 系列）Mac，macOS 13 或更新版本。本次不提供 Intel 安装包。
- 一个具有管理员安装权限的本地用户；安装目标是当前登录用户。
- 语音功能需要自行开通的百炼或火山引擎语音服务及对应凭据。

从 [v0.1.23 发布页](https://github.com/weipao163-ctrl/squirrel-voice-input/releases/tag/v0.1.23) 下载 `.pkg` 与同名 `.pkg.sha256`。将两者放在同一目录，在该目录执行：

```bash
shasum -a 256 -c SquirrelVoiceInput-0.1.20261010.2-arm64.pkg.sha256
```

确认显示 `OK`，再双击安装包。应用版本为 0.1.23，Installer 的构建版本为 0.1.20261010.2。

## 首次安装的系统放行

**安装包使用本地证书签名，未经过 Apple Developer ID 签名与公证。首次安装可能需要手动允许。**

1. 首先双击下载的安装包，使系统显示拦截提示。
2. 打开“系统设置 → 隐私与安全”（部分系统显示“隐私与安全性”），在安全性区域找到刚刚被阻止的安装包。
3. 确认安装包来自本项目发布页且校验通过，点击“仍要打开”，按系统提示确认并输入 Mac 的管理员密码。
4. 继续完成 Installer 安装流程。更新时若提示增强版有未保存设置，请保存或取消；退出取消时会保留旧安装。

这是 macOS 针对未公证应用的正常放行流程，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。不需要关闭 Gatekeeper、SIP 或全局安全检查。如果系统报告文件已损坏、校验失败或来源不同，请重新下载并核验，而不是忽略异常。

## 添加输入法与设置语音

1. 安装完成后保存工作，注销当前用户并重新登录。首次注册的输入法需要刷新登录会话。
2. 打开“系统设置 → 键盘 → 文本输入 → 编辑 → ＋”，在“简体中文”中添加“鼠须管增强开发版”，然后从菜单栏选中它。
3. 从输入法菜单打开增强设置，按需启用字母选词与语音。首次默认关闭增强功能，已有设置不被默认值覆盖。
4. 在“语音输入设置”中填写自己的模型、服务地域与凭据，录制长按热键，选择可用麦克风，保存并应用。两个千问模型共享千问凭据；豆包需要已开通的语音识别资源，火山方舟通用 Key 不等于语音服务权限。
5. 通过设置页申请麦克风和输入法焦点检测权限，直接处理 macOS 系统弹窗。可在“隐私与安全”中检查麦克风及辅助功能授权。
6. 鉴权通过后，在测试框按住热键说话，松开后自动识别并输入。云识别会向自己配置的服务上传音频，可能按账号计费。

使用细节见 [使用说明](USAGE.md)，数据与网络范围见 [隐私说明](PRIVACY.md)。新电脑不会继承其他电脑的 API Key、麦克风配置或权限。

## 安装与更新位置

程序安装到当前用户的 `~/Library/Input Methods/SquirrelEnhancedDev.app`。设置、个人词库与备份保存在 `~/Library/Application Support/SquirrelEnhancedDev`。增强版使用独立输入源和数据目录，更新保留自己的设置与词库；不覆盖正式鼠须管。

安装包只含程序、公开默认词库与默认外观、安装脚本和许可证，不含开发者的个人词库、学习记录、用户设置、API Key 或签名私钥。本机迁移个人词库属于用户自己的操作，不会使词库进入发布包。

组件测试、空白数据检查和本机用户验证不能代替所有 Mac 与所有输入控件的实机验收。已完成的验证与限制见 [验证范围](VALIDATION.md)。
