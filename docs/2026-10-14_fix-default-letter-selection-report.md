# 0.1.31：首次安装默认启用字母选词

新电脑首次安装后，默认朙月拼音可直接使用两阶段字母选词：输入拼音，首次空格展开候选，按 `asdfghjkl` 选择当前页候选；第二次空格确认高亮项。无需打开设置、保存一次或额外点击“确认应用并重新部署”。正常的输入法首次部署和系统输入源添加仍需完成。

App 与 Helper 均为 0.1.31；Apple Silicon 完整安装包的构建号为 0.1.20261014.31，要求 macOS 13+。语音仍默认关闭，需要用户自己的服务凭据、热键和系统权限。

## 根因与修改

E-1 → F-1 → P-1：旧 `Settings` 的方案集合为空，新增 `LetterProfile` 默认关闭；包内只有资源目录的生产 Lua，没有为默认方案接入处理器。GUI 部署按钮才会创建用户 Lua/方案补丁并重部署，所以新安装不能仅靠正常首次部署获得字母选词。

P-1：缺少设置文件 → 默认朙月拼音配置启用 → 首个真实输入会话应用运行开关。Codable 按原值读取已有方案集合，空集合和明确关闭均不自动升级为启用；损坏配置保留原文件，使用已验证备份或禁用回退。

P-2：构建 → 公开词库 → `bundle_default_letters.py` 打包声明的朙月拼音默认补丁与共享生产 Lua → 预编译 → 签名 → 安装包。两个构建入口均使用这一顺序；程序首次正常部署即可加载首位处理器、9 项、`asdfghjkl` 和空格前隐藏规则。此路径不生成用户设置、字母补丁或用户 Lua，不读取个人词库。

E-2 → F-2 → P-2：真实包内 Rime 在新的数据目录完成首次部署；第一段拼音不提前提交，首次空格不提交，字母选择实际候选成功。关闭运行开关后，原方案空格提交恢复；`lovewin2k` 数字混输保持原文。

P-3：用户 `.custom.yaml` 优先于共享默认补丁。GUI 后续修改页大小时，仅在默认方案、无用户补丁/所有权记录、共享模板字节匹配、已部署默认标记有效及首位处理器唯一时，将共享插入还原为规划基线，再生成可恢复的用户补丁；避免重复处理器。已有或外来处理器沿用原来的所有权保护。

## 用户数据与验收边界

本机继续使用现有词库。本轮没有安装发布词库去替换本机资源，没有修改个人词库、学习记录、设置或 API Key，也没有采音、读 Keychain 凭据或调用云识别。下载的公开雾凇词表继续进入 GitHub 源码和完整安装包；来源、许可证与哈希固定，排除个人词库、用户补丁和凭据。

默认启用针对本包提供的朙月拼音；其他方案和已有用户自定义仍遵循自己的配置及显式部署流程。首轮空白目录检查不能冒充第二台 Mac 的真机安装。此次没有第二台 Mac 实机验收。

安装包为本机证书签名，未经 Apple Developer ID 签名与公证；首次安装被拦截时，需要在“系统设置 → 隐私与安全”手动允许。详见[安装说明](INSTALLATION.md)。
