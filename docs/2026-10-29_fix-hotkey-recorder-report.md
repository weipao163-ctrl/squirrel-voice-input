# 0.1.38：新电脑无法录入语音热键

2026-10-29。已构建并更新本机至 0.1.38，尚未发布到 GitHub。本版包含 0.1.37 的输入源注册修复。针对用户报告的“点击设置后，左右 Option / Control / Shift / Command 都录不进去”，修正本地按键事件处理与录制恢复。另一台电脑尚未进行安装后验收，不能仅凭芯片型号判断原因。

## 证据与原因

E1：旧版 `HelperModel.keyMode` 的本地监听器收到 `flagsChanged` 后，调用 `CGEventSource.keyState(.combinedSessionState, ...)` 判断事件方向。前者是窗口收到的事件，后者返回调用当下的 Quartz 状态；旧事件被排队处理时，两者可能已不同。返回 false 时，旧版会把修饰键按下当作松开，无法建立正确的录制集合。设置里的语音测试框采用了同样的处理。

E2：原生夹具创建真实 AppKit 修饰键事件，模拟事件仍包含按下状态但物理键已松开的场景。故障对照将旧的实时状态查询重新放回隔离副本；新代码直接读取事件状态。夹具不注入系统按键，不监听用户其他窗口，不采音、不调用云服务或 Keychain。

E3：用户确认按的是支持的左右修饰键，而非 Fn/地球或普通字母键。另一台电脑的系统版本、权限状态和真实事件序列未取得，因此不声称已证明该机器具体由权限、芯片或哪一种延迟触发。

F1（E1、E2）：事件与回调时全局状态混用存在可复现的录制缺陷。P1：本地按下事件排队 → 物理键已松开 → 回调读取“当前键已抬起” → 按下记录丢失 → 无法录入绑定。修复切断这条时间依赖。Apple 对两类信息的说明见 [NSEvent 的事件属性](https://developer.apple.com/documentation/appkit/nsevent) 和 [CGEventSource.keyState](https://developer.apple.com/documentation/coregraphics/cgeventsource/keystate(_:key:))。

## 修复

- 从每个事件的 `modifierFlags` 与 `keyCode` 判断方向，使用 SDK 公开的左右修饰键位；事件提供方没有左右位时，按本地事件周期区分左右键。不会把左右 Option 合并为一个键。
- 热键录制、取消后的松键收尾，以及设置页测试框使用同一解码逻辑。普通生产输入法的全局按键状态机不在此次改动范围。
- 开始录制时结束设置窗口当前文本编辑，包括 API Key 的安全输入框，再接收本窗口按键；不增加全局键盘监听或请求额外监听权限。
- 单独收到松键时不保存空绑定。Fn/地球等不支持按键会在热键控件旁显示原因，保留原绑定。
- 因失焦漏收松键后，右侧设置按钮仍可点击；确认物理键已经全部释放后再开始新录制，避免界面永久禁用。

## 验证结果

167 项 Core 检查通过。93 项键盘检查最终独立运行全部通过；并行构建期间曾有一项等待初始化回放的时序检查失败，原始失败记录保留，未据此改变生产键盘代码。127 项原生编辑器/浮窗/录制检查通过；把旧实时状态查询放回隔离副本后，延迟 Option 录入、双侧组合、按下/松开计数和取消后松键共 4 项失败，修复版对应项全部通过。入口的“所有按键已释放”快照在夹具中明确注入，避免测试受用户在其他窗口打字干扰；真正被测试的是生产事件处理方法。

## 验证方式

```bash
python3 tools/run_macos_core.py --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
python3 tools/run_native_voice_editor.py --negative-hotkey-state-query
python3 tools/run_native_voice_editor.py
```

Core 检查覆盖八个左右修饰键、同时按住同类左右键、缺少左右标志位及重复事件。原生检查执行实际 HelperModel 录制方法，覆盖延迟按下、双侧组合、热键测试计数、取消松键、孤立松键和 Fn 提示。测试环境使用已有兼容 SDK，其他机器应按构建说明选择本机可用的 SDK。

本机设置界面确认可从 API Key 安全输入框进入热键录制，并可取消且保留原绑定。自动化接口不支持单独注入修饰键，因此 GUI 的物理 Option 录入不算已验收；已验证的修饰键录制来自上述原生 AppKit 夹具。另一台电脑仍需安装后按实际键验证。

公开安装包只含公开默认词库，不含本机个人词库、设置、API Key、录音或签名私钥。本机更新仍复用原词库和设置。
