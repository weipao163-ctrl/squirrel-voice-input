# 隐私与发布边界

## 本机数据

- API Key 与 Access Token：通过 macOS Keychain 管理。
- 设置：独立增强版的数据目录中保存模型、服务地域、热键、设备选择和凭据引用。
- 个人 Rime 词库与学习记录：保留在用户数据目录；不进入默认构建资源或本仓库。
- 可恢复语音草稿：可能包含用户识别文本，按源码实现留在本机，不是公开测试数据。
- 开发签名：在当前副本的 `build/` 生成，私钥仅用于开发者自己的构建。

迁移个人词库的工具只供用户主动在自己的电脑使用；代码存在不表示词库内容已经随仓库上传。

## 网络与权限

按住热键或主动测试才开始采音。云识别向用户配置的百炼或火山引擎发送音频；连接鉴权也会携带配置凭据联系对应服务，但不采音。识别费用、保留政策及服务地域由账号与提供商设置决定，项目不承诺离线识别或服务端零保留。

输入法使用 macOS 原生输入会话和辅助功能校验目标，以防切换应用后错写。目标定位诊断输出固定状态与能力标志，不用于收集输入正文或文件名。其他诊断报告可能包含本机路径与设备信息，公开提交前仍应脱敏。

## 仓库边界

公开内容是代码、人工编写的公共文档、离线夹具和带许可证的默认资源。排除 `dist/`、`build/`、`download/`、`evidence/`、运行时配置、钥匙串内容、签名私钥、个人词库、学习库、录音、日志及聊天历史。

`.gitignore` 只是辅助。每次发布前运行 `python3 tools/check_public_source.py`，并审查 `git diff --cached`。检查脚本直接读取 Git 暂存区的文件内容，并校验公开默认资源的来源哈希，能拒绝禁止路径及常见凭据模式，不能保证识别所有格式的秘密，因此新增文件和历史提交仍需人工审查。

首次公开仓库从干净副本建立新的 Git 历史，没有导入原工作区历史或本机证据。不要向本仓库提交用户数据来复现问题。
